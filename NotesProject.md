# Para manipular, unir, dividir y editar PDFs 📕

```bash
npm install pdf-lib
```

# Para manejar la subida de archivos (Multer ya viene en Nest, pero instalamos tipos)
```bash
npm install --save-dev @types/multer
```

# Para conversión de Imágenes a PDF y viceversa
```bash
npm install canvas
```

# Alternativa potente para transformaciones de imagen
```bash
npm install sharp
```
